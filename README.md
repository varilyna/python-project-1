# Python-project-1
## Текстовый редактор 

### Описание проекта 
Текстовый редактор, позволяющий изменять и сохранять файлы. 

### Реализуемый функционал 
1. Возможность редактирования файла
2. Перемещение по тексту при помощи “стрелок” - по словам, в начало/конец строки
3. Удаление строк и слов
4. Текстовый поиск и замена
5. Хоткеи для сохранения и выхода

### Архитектура 
Класс `TextEditor`:

- Атрибуты:
    - `root`: главное окно приложения Tkinter.
    - `textarea`: текстовая область для редактирования текста.

Класс `View`:
- атрибуты:
    - `theme`: тема
    - `font`: шрифт

- методы:
    - `change_theme`: изменить тему
    - `change_font`: изменить шрифт

Класс `Menu`:
- методы:
    - `open_file`: открыть файл
    - `save_file`: сохранить файл
    - `exit`: выйти из текстового редактора
